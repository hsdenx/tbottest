tbottest.initconfig¶

helper functions¶

Values of the lab and the board configuration (ini or JSON) are read through these functions, or the methods of IniTBotConfig and IniConfig built on them, never through config_parser directly. Then the order of the sections (TC_BOARDNAME before TC, LABHOST_<labname> for the lab host) is known in one place.

tbottest.initconfig.init_get_config(cfgp: RawConfigParser, name: str, default: str) → str[source]¶

returns value of key name from configparser.

Searches the sections init_config_sections() returns, while a testcase runs first “TC_BOARDNAME.TESTCASENAME”, then “TC_BOARDNAME”, then “TC”. If not found, return default value. If the value is “None” return None

So what happens without the key is up to the testcase. The generic testcases pass a default that means “not set” and are decorated with tbottest.tc.generictestdef.require_cfg(), so they are skipped and tbottest.tc.generic_board.generic_lnx_all() counts them as skipped. A testcase that cannot do without the key should raise an exception, so it fails.

Parameters:

  • cfgp – current config parser

  • name – name of key

  • default – default value if key is not found

tbottest.initconfig.init_config_sections() → list[source]¶

returns the sections of the board configuration in the order init_get_config() searches them

While a testcase runs (see init_testcase()) first “TC_BOARDNAME.TESTCASENAME”, then “TC_BOARDNAME” and “TC”, else only the last two. There is deliberately no section “TC_TESTCASENAME” for all boards, a value for all boards goes into “TC”.

tbottest.initconfig.init_read_inifile(filename: str) → RawConfigParser[source]¶

returns a configparser with the ini file filename read, the way IniTBotConfig and IniConfig read theirs

For code that has to read an ini file before IniTBotConfig and IniConfig exist, e.g. set_board_cfg() in boardspecific.py. Read its values with the init_*_config functions.

Parameters:

filename – path of the ini file

tbottest.initconfig.init_read_jsonfile(filename: str, flags=None, tbotcfgp=None) → RawConfigParser[source]¶

returns a configparser with the JSON configuration filename

The file holds an object of sections, each an object of keys, as the ini file has them. Names and values get their expressions replaced, see init_config_substitute(), values become strings, see init_json_value_to_str(). configparser then interpolates ${key} and ${section:key} as for an ini file.

Parameters:

  • filename – path of the JSON file

  • flags – the tbot flags, default those of the command line

  • tbotcfgp – configparser of tbot.json, for the board file

tbottest.initconfig.init_read_configfile(filename: str, tbotcfgp=None) → RawConfigParser[source]¶

returns a configparser with the configuration file filename, JSON if its name ends in .json (init_read_jsonfile()), else ini (init_read_inifile()); in both the expressions of init_config_substitute() are replaced

Parameters:

  • filename – path of the file

  • tbotcfgp – configparser of tbot.ini or tbot.json, for the board file

tbottest.initconfig.init_config_substitute(text: str, flags, tbotcfgp=None, where: str = '') → str[source]¶

returns text with the expressions of a JSON configuration replaced

  • ${env:NAME} and ${env:NAME:-default}, the environment variable NAME

  • ${flag:NAME} and ${flag:NAME:-default}, the value of the tbot flag NAME:<value>, True for a flag NAME without value

  • ${lab:key}, key of the lab section of tbot.json (LABHOST or LABHOST_<labname>), only with tbotcfgp

  • ${tbot:SECTION:key}, key of SECTION of tbot.json, only with tbotcfgp

The default is only used, and only replaced, when the value is not set; without default a missing value raises RuntimeError. Expressions may be nested; any other ${…} stays for the interpolation of configparser (${key}, ${section:key}), with the expressions in it replaced, and $$ stays as it is.

Parameters:

  • text – value or name from the JSON file

  • flags – the tbot flags

  • tbotcfgp – configparser of tbot.json, for ${lab:} and ${tbot:}

  • where – file name for the error messages

tbottest.initconfig.init_substitute_configparser(cfgp: RawConfigParser, flags=None, tbotcfgp=None, where: str = '') → RawConfigParser[source]¶

returns a configparser with the expressions of init_config_substitute() replaced in the section names, keys and values of cfgp, so an ini file can use them as a JSON file does

Parameters:

  • cfgp – configparser of an ini file

  • flags – the tbot flags, default those of the command line

  • tbotcfgp – configparser of tbot.ini, for the board file

tbottest.initconfig.init_json_value_to_str(value, subst=None) → str[source]¶

returns a value of a JSON configuration as the string configparser holds, as the ini file would have it

Strings stay strings, true/false become True/False, null None, numbers their digits, lists and dictionaries their Python literal, which the code reads with ast.literal_eval as from an ini file.

Parameters:

  • value – value from the JSON file

  • subst – function that replaces the expressions in a string, see init_config_substitute()

tbottest.initconfig.init_config_to_json_dict(cfgp: RawConfigParser, resolved: bool = False) → dict[source]¶

returns the configuration of cfgp as the object of a JSON configuration, see init_read_jsonfile()

Values that are a Python list or dictionary become JSON lists and objects, every other value stays a string.

Parameters:

  • cfgp – configparser of an ini or JSON configuration

  • resolved – True gives the values interpolated, as tbot reads them (a reference that does not resolve stays as written); False as they are written, with ${…}
